# TaskFlow AI – Smart Productivity & Work Automation Assistant

**HACKATHON TRACK:** Future of Work & Automation

---

## 📌 Problem Statement
Students, developers, freelancers, and small teams often struggle with task prioritization, deadline management, daily planning, and decision fatigue. People spend too much time deciding what to work on, organizing deadlines, and manually planning their day instead of focusing on deep, meaningful work.

---

## 💡 Solution
**TaskFlow AI** is a modern SaaS web application that helps users organize their work, automatically prioritize tasks using Google Gemini AI, generate smart daily schedules, track deadlines, and receive real-time productivity analytics and coaching insights.

---

## ✨ Key Features
- 🚀 **Smart Task Management**: Full CRUD operations with categories (Work, Study, Personal, Development, Meeting, Other), priority badges, search, and filter modes.
- 🧠 **AI Priority Detection**: Sends pending tasks to Gemini AI to automatically calculate priorities (High, Medium, Low) along with concise rationale.
- 📅 **AI Daily Planner**: Generates a structured time-blocked chronological daily schedule tailored to today's pending tasks.
- 📊 **Productivity Analytics**: Real database analytics showing completion rates, task status distribution (Pie Chart), and 7-day completion trends (Bar Chart) built with Recharts.
- 🤖 **AI Productivity Summary**: Actionable coaching summary generated by Gemini AI analyzing real task completion history.
- 🔔 **In-App Notifications**: Real-time alerts for overdue tasks, tasks due today, and high-priority upcoming deadlines.
- 🌓 **Dark / Light Mode**: Theme toggle with persistent local state.
- 🔐 **Secure Authentication**: JWT-based authentication with password hashing via `bcryptjs`.
- 🌱 **Demo Seed Script**: Built-in script (`npm run seed`) to quickly populate realistic demo tasks for instant hackathon presentations.

---

## 🛠 Tech Stack

### Frontend
- **Framework**: React with Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Charts**: Recharts
- **Router**: React Router v6
- **HTTP Client**: Axios

### Backend
- **Runtime**: Node.js
- **Framework**: Express.js
- **Database**: MongoDB with Mongoose
- **AI Model**: Google Gemini API (`@google/generative-ai`)
- **Authentication**: JSON Web Tokens (JWT) & bcryptjs

---

## 🔑 Environment Variables

Create a `.env` file inside the `server/` directory:

```env
PORT=5000
MONGODB_URI=mongodb://127.0.0.1:27017/taskflow
JWT_SECRET=taskflow_ai_jwt_secret_key_2026_secure
GEMINI_API_KEY=your_gemini_api_key_here
```

---

## 🚀 Installation & Running

### 1. Backend Setup
```bash
cd server
npm install

# (Optional) Seed realistic hackathon demo data:
npm run seed

# Start server:
npm start
```

### 2. Frontend Setup
```bash
cd client
npm install

# Start Vite dev server:
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
